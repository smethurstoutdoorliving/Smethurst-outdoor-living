SMETHURST OUTDOOR LIVING WEBSITE

This is a complete static website for Smethurst Outdoor Living.

Files:
- index.html   Main website
- style.css    Styling and responsive layout
- script.js    Mobile menu and gallery lightbox
- images/      Your supplied project photographs and logo

To use it:
1. Keep the folder structure exactly as supplied.
2. Upload the contents to your web host's public_html/www folder.
3. Set index.html as the homepage if your host asks.

The phone number and Instagram link are already included.
The enquiry CTA currently uses click-to-call; if you want a proper enquiry form,
connect it to your chosen form service/hosting email after choosing your host.

IMPORTANT:
All gallery photos currently come from the photographs supplied in this conversation.
